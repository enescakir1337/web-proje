# Web Projesi

Bu proje, PHP backend ve modern HTML/CSS/JS frontend bileşenlerinden oluşan bir web uygulamasıdır.

## Proje Yapısı
- **backend/**: PHP API uç noktaları, veritabanı bağlantısı ve yönlendirici (router)
- **frontend/**: Kullanıcı arayüzü, dashboard, QR ve yönetim sayfaları
- **baslat.bat**: Projeyi yerel ortamda çalıştırmak için başlatıcı betik
